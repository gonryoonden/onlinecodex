# 품질과 범위의 한계

- 제품 상태는 부분 완료. 일반 편집과 로컬 파일 기능을 실제 테스트하지만 라이브 Gemini 키가 없으므로 자동 인식 품질을 완성으로 표시하지 않습니다. 모델 런타임 점검/구조화 JSON/오류 처리는 구현됨, 실계정 연동은 BLOCKED.
- 수동 영역 지정은 오프라인에서 실제 동작합니다. 자동 OCR이 수행된 것처럼 표시하지 않습니다. 텍스트/단순 도형은 native, 장식 이미지는 PNG입니다. 다각형이 없으면 ‘근사 크롭’입니다. 마스크 존재 자체가 객체 의미나 경계 정확성을 보증하지 않습니다.
- 단색/그라데이션 배경은 사용자가 확인한 근사 재구성입니다. 가려진 원본 디테일은 알 수 없습니다. 복잡한 배경 inpainting은 미구현이며 원본 배경을 유지하고 ‘배경 보정 필요’ 경고를 표시합니다. 텍스트 이동 시 잔상이 남는 결과를 정확한 분리라고 표시하지 않습니다.
- 다각형은 원본 픽셀의 alpha clip입니다. 브러시 기반 픽셀 마스크/구멍/hole 편집, Google의 base64 segmentation mask 디코딩은 미구현입니다. 꼭짓점을 다시 찍거나 영역 좌표 재지정/재분석을 사용하세요. 마스크는 정수 ROI에서 원본을 일대일로 복사하며 불투명 core RGB는 합성 픽스처로 검증합니다. 알파 경계는 캔버스의 다각형 보간과 입력 이미지 색상 프로파일 때문에 완전 동일성을 보장하지 않습니다. 기존 fidelity source-masked 인증을 임의로 부여하지 않습니다.
- 편집 지원 요소: 텍스트, 사각형/둥근 사각형/원/선, 이미지. 기존 Canvix의 미디어/그룹/테이블/애니메이션은 노출하지 않으며 프로젝트 가져오기에서 거부합니다. PPTX 가져오기는 인터페이스 확장 지점만 있고 미구현입니다.
- PNG는 현재 페이지, PDF/PPTX는 모든 페이지. PPTX는 native text/shape/image와 native gradient를 사용합니다. 폰트는 임베드하지 않습니다. PowerPoint 기기에 Noto Sans KR 설치 권장. 브라우저/Office 글꼴 측정과 줄간격 차이로 텍스트 줄바꿈은 다를 수 있습니다. PDF는 래스터 페이지이므로 native PDF 객체 편집은 제공하지 않습니다.
- 30페이지, 페이지당 500개, 캔버스 32~8000px. 이미지 18MB, 40MP, 한 변 12000px. AI는 9MB 요청/16MP, 동시 1건/기본 일 20회(서버 프로세스 메모리 카운터). 일일 카운터는 서버 재시작에 보존되지 않고 다중 인스턴스에 공유되지 않습니다. 사용자별 DB quota는 없습니다. 기본 요청의 최대 2회 재시도는 추가 과금/쿼터를 소모할 수 있습니다.
- IndexedDB는 브라우저/도메인별 저장입니다. 브라우저 데이터 삭제·시크릿 모드 종료·디스크 손상·저장 완료 전 강제 프로세스 종료 시 영구 보존을 보장할 수 없습니다. 저장 실패 상태와 수동 ZIP 백업이 제공됩니다. 저장 대기 시 종료 경고를 표시합니다. 주기적으로 ZIP 백업을 외부에 보관하세요.
- 모바일 전체 편집 최적화와 계정 간 동기화는 범위 밖입니다. 1366×768 데스크톱 Chrome 기준으로 검증합니다.
- 운영 의존성 보안 감사는 별도 JSON 증거 참조. 개발용 ESLint/minimatch 중간 심각도 경고는 호환성을 깨는 강제 하향 버전 변경으로 감추지 않았습니다.
- 라이브 Gemini·민감 자료의 무료 티어 전송 적합성·Windows·개인용 HTTPS 배포·실제 Microsoft PowerPoint GUI는 환경/권한이 없어 미검증입니다. PPTX는 XML/ZIP 검사, python-pptx 및 LibreOffice 렌더링 결과를 구분해서 보고합니다.

- 기존 fidelity validator는 소스 배경·마스크 SHA·픽셀 합성 증거와 소스 비교 QA의 명시적 통과를 요구합니다. Studio 사용자가 편집한 일반 문서는 그 인증 대상이 아니며 어댑터는 QA 플래그를 거짓으로 true로 바꾸지 않습니다. 검증되지 않은 `user-approved-rasterization` foreground는 strict fidelity 인증을 통과하지 않습니다. PPTX 파일 구조·native 객체 검증과 원본 충실도 인증을 구분하며 정수 ROI·원본·단순 배경이 있는 polygon-mask는 PPTX 어댑터에서 보존된 fidelity.validate_masked로 검증하여 통과할 때만 source-masked로 기록합니다. 부적합/잔상/8MP 초과 소스는 비인증 출처로 기록합니다. 페이지 전체의 source 비교 QA 인증과는 구분합니다.

- 모델의 의미적 환각·누락은 schema 검사만으로 판정할 수 없습니다. 이 버전은 정확한 판독을 자동 보증하지 않으며 모든 추정 텍스트를 확인 필요로 처리합니다. 라이브 품질 확인 전 민감/중요 자료의 무검토 자동 변환에 사용하지 마세요.
