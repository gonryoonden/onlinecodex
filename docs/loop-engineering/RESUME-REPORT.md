## 새로 제공하는 흐름

1. PNG/JPG 업로드 → 기존 Gemini 분석 또는 수동 박스 후보 입력
2. **AI 객체 투명 분리 · 기기에서 실행** → 최초 모델/실행 파일 약 57MB를 같은 사이트에서 다운로드, 브라우저 Worker의 WASM CPU로 실제 MobileSAM 실행
3. **국소 배경 추정** 검토 확인 → 결과 미리보기 → 독립 레이어 생성
4. 텍스트·벡터 수정, 알파 이미지 이동·크기 변경·삭제 → 프로젝트 ZIP 저장/새 브라우저 복원 → PNG/PDF/네이티브 PPTX 출력

이미지는 분할 모델로 전송하지 않는다. 모델 처리에는 API 키·추가 추론 서비스·신규 과금이 없다. 기존 Gemini 분석의 외부 전송 동의/무료 티어 제한은 유지한다. 기존 마스크·다각형·키잉·알파 브러시와 원본 페이지/에셋도 유지한다.

## 인프라 / 재현

[모델 비교](MODEL-EVALUATION.md), [고정 모델 manifest](../../apps/studio/public/sam/manifest.json), Apache-2.0/MIT 고지와 원본 체크포인트 해시를 보존했다. ONNX 모델 44,322,987 bytes + WASM 약 13MB. 모델을 같은 앱의 정적 파일로 제공해 Vercel Python/Torch 함수나 별도 서버가 필요 없다.

실측 CPU 기준: 초기화·임베딩 약 1.9초, peak RSS 약 681MiB. 브라우저 모델 처리 약 13.1초(현재 환경 기준). 브라우저 전체 peak 메모리를 681MiB로 측정한 것은 아니다. 현재 Chromium의 WASM 단일 스레드 경로만 실제 검증했고, WebGPU/저메모리 모바일은 미검증이다. 최초 다운로드/CPU 사용을 표시하고 취소를 제공한다.

프런트엔드 재현은 `npm ci`만으로 가능하며 ONNX와 WASM은 같은 앱에 포함된다. PyTorch 환경은 기준 모델 재현/다시 내보내기에만 필요하다. 추론 입력으로 사용하지 않는 CPU 기준 마스크를 추적된 fixture에 보존해 work/ 임시 파일 없이 브라우저 테스트를 재실행할 수 있다.

```sh
cd apps/studio
npm ci
STUDIO_EXTERNAL_INFOGRAPHICS=/absolute/path/to/two-originals npx playwright test tests/sam-browser.spec.ts
```

실제 추가 원본의 고정 링크/해시는 [기존 자료 목록](../integrated-beta-review.md#재현)을 따른다. 원본 JPG 입력 검증은 실제 Roles PNG를 JPEG quality 92로 변환해 수행했다.

## 중단과 다음 과제

24회 예산을 소진했으므로 추가 구현/재검증을 중단했다. 이전 13회 기록을 초기화하거나 예산을 늘리지 않았다. 새 Gemini 호스트는 여전히 환경 허용 목록 밖이고 새 실호출은 0회다.

후속 개발에는 승인된 추가 반복 예산이 필요하다. 내부 구멍이 있는 클립/안경, 여러 객체가 한 박스에 있는 경우, 카드의 인쇄 글자와 가림 관계, 정밀 그림자/질감 복원, 추가 실제 Gemini 응답과 브라우저별 메모리를 우선 검증해야 한다. 유료 모델/서비스가 필요하면 별도 승인 범위를 지켜야 한다. 이번 변경은 **부분 베타**로 제공하며 전체 완료 판정은 하지 않는다.
