# 자동 편집·예외 검토 베타 — 2026-11-11

**부분 개선. 전체 완료 기준은 미충족이다.** 확인 여부에 따른 전역 차단을 제거하고, 검증 가능한 객체는 업로드 동의 후 자동으로 편집 화면에 연결했다. 그러나 한국어 원본의 상세 검토 비율은 아직 54.3%로, ‘소수 예외만 검토’ 목표에 도달하지 못했다. 새 Gemini 실호출은 환경 차단으로 0회다.

## 원인과 변경

기존 `reviewed=false`는 유효 마스크가 있어도 모든 배경 복원을 막았다. 생성된 객체도 숨겼고, 복원 성공 객체까지 provenance의 review/backgroundWarning과 일괄 문구로 검토 대상으로 표시했다. 추출 성공·배경 안전성·사용자 확인을 같은 상태로 취급한 것이 직접 원인이다.

이제 전송 동의와 품질 증거를 분리한다. A 준비, B 측정된 근사 경고(즉시 편집), C 실제 마스크/복원 위험, 분리 실패를 배타적으로 계산한다. B에는 방향별 추정 차이·색상/밝기 변화·주변 경계 급변 검사 근거를 저장한다. 내부 배경이 알파 안에 크게 포함된 클립·안경·가위를 자동 적용 전에 차단한다. 점수/면적/spill·인접 후보·원자적 쓰기 보호를 유지한다. 세부 정책은 [ux-POLICY.md](ux-POLICY.md).

업로드 → 해당 이미지의 외부 전송 동의 → Gemini/저장 분석 → MobileSAM → 검사/복원 → 독립 페이지를 직접 실행한다. 버튼 자동 클릭이 아니다. 취소 시 완료된 분석을 원본 페이지와 제한된 세션 캐시에 보존한다. 재시도·ZIP 재열기에서 분석을 재사용한다. 최초 약57MB 안내, 실제 단계/마스크 개수, 취소를 제공한다. 임의 진행률은 사용하지 않는다.

예외 목록은 C/분리 실패만 표시한다. 선택 객체의 원본/분리 결과 확대 비교, 알파 브러시, 기존 단색 키잉을 이용한 실제 내부 배경 제거, 해당 객체 재분리, 배경 재검사, 원본 유지와 교정 적용을 제공한다. 확인 클릭을 품질 개선으로 기록하지 않는다. 고급 수동 경로를 유지하며 교정 페이지 생성 시 기존 정상 객체의 편집을 보존한다.

추가 두 원본은 **사람이 지정한 박스**, 모델이 실제 만든 마스크다. 실제 Gemini 인식 3종 성공으로 보고하지 않는다. EDA의 수정 마스크는 수동 교정이며 자동 마스크 성공에 추가하지 않는다. Roles의 복잡한 배경은 자동 성공이 아니며, 단색 교정은 숨은 무늬를 복원하지 않는다.

3종 모두 텍스트 수정·사용자 네이티브 도형 수정·이미지 이동/크기 변경/삭제, ZIP 새 브라우저 복원, PNG/PDF/편집 가능한 PPTX 출력 통과. 선언한 복원 사각형 바깥 변경 픽셀0. 한국어 안전모의 원래 영역 노란 본체 픽셀은 18,235→0. 이는 본체 색상 잔상 검사이며 그림자/숨은 질감의 정답 점수가 아니다.

## 검사와 단계

- 1 원인/루프 구축: 통과. 기존24회 상태와 로그 불변, 별도12회 상태/복구/중단 규칙·체크포인트.
- 2 판정 정책: 코드/검사 통과. 의미적 정밀도 전체 인증은 아님.
- 3 자동 진입: 실제 모델/브라우저 통과. 정상 경로 객체별 승인·SAM 클릭·생성 승인0.
- 4 통합/회귀: 통과. 단위119 통과·외부 corpus 조건부1 생략, 루프7 통과, 브라우저9 통과. 실제 계산 취소/재시도에서도 분석 요청1회. TypeScript/ESLint/production build 통과. 동일한 최적화 빌드에서도 실제3종 브라우저3개 통과.
- 실제 출력3종: OOXML 전체 XML/관계 검사, python-pptx 열기, LibreOffice PDF 렌더링 및 편집 문자열 보존 통과.
- 5 최종 품질: **미충족**. 상세 검토가 아직 다수, 인쇄 글자가 있는 이미지 카드와 내부 글자의 복원/가림 관계 미해결, 숨은 무늬/그림자/동일 색 기하 구조의 일반적 정확도 미입증. 새 Gemini 호스트 차단.
- 6 Preview: **부분 검증**. 배포 READY, 실제 capabilities·모델 manifest HTTP200과 선언된 고정 해시 일치. 실행 환경 프록시가 Preview 호스트 CONNECT를403으로 거절해 호스팅 UI는 미검증. 동일 최적화 빌드의 로컬 브라우저3종은 통과. 배포 READY를 편집 흐름 완료로 판정하지 않는다.
