## 배경 품질과 남은 문제

단색 국소 복원과 명시적 수동 단색 대체를 검증했다. 교정색 이음새·그림자·숨은 질감·마스크의 의미적 정확도는 자동 보장하지 않는다. 다각형은 사용자가 지정한 근사 윤곽이며 정밀 모델 분할의 증거가 아니다. 이미지 내부에 인쇄된 텍스트, 복잡한 포함 관계 및 중첩 객체는 계속 교정 대기가 될 수 있다. 원본 페이지/에셋은 유지하고, 준비되지 않은 객체는 원본 위에 겹쳐 보이지 않도록 숨긴다. 숨김 후보를 실제 준비 완료 객체 수에 포함하지 않는다.

새 구조는 준비되지 않은 후보를 버리는 문제와 저장 후 교정 정보를 잃는 문제를 해결했지만, 실제 응답의 마스크 부재 자체를 해결한 것은 아니다. `segmentation=combined`라는 과거 메타데이터는 요청 방식이며 마스크 성공 개수가 아니다.

## 중단 이유 / 재개

현재 실행 환경에서 `generativelanguage.googleapis.com` 연결이 프록시 403으로 차단된다. 새 Gemini 호출·API 과금·키 변경은 하지 않았다. 저장된 실제 응답은 `evidence/studio/phase3/gemini-live-improved.json`(gemini-3.5-flash-lite, 원본 2752×1536)에 한정했다. 다른 두 원본의 인수 테스트는 사람의 영역 목록을 API 경계에 주입한 편집 테스트이며, 실제 Gemini 인식/자동 분리 성공이 아니다.

추가 반복으로 검사 임계값을 낮추거나 사각형 크롭을 분리 성공으로 바꾸지 않고, 상태를 저장해 중단했다. 재개 조건은 허용된 기존 무료 API 경로에서 실제 마스크 응답을 확보하거나 검증 가능한 추가 실제 분석 응답을 제공받는 것이다. 복잡한 중첩/질감의 배경·경계 검증도 남아 있다. 새 유료 서비스나 추가 API 과금이 필요하면 기존 승인 범위를 넘기지 않는다.

```sh

# 환경 중단으로 running 시:
python scripts/pms-loop.py recover
# 증거/환경 제한을 해결한 뒤 5단계부터 남은 예산 내에서 재검증:
STUDIO_EXTERNAL_INFOGRAPHICS=/absolute/path/to/inputs \
python scripts/pms-loop.py run 5 browser --cause resolved-cause --hypothesis 'what changed and why it should pass'
```
